# Configuration

Manifold configuration is centered on the local gateway, providers, routes, and
usage visibility.

## Gateway

The default base URL is:

```text
http://127.0.0.1:17680/v1
```

The host is loopback only. The port can be changed in Settings if another local
process already uses `17680`. Every request requires `Authorization: Bearer
ldd_<your-key>` or an accepted compatible key header for Anthropic-style clients.
For tools inside a development project, use a short-lived Local Session Key such
as `mf_session_<short-lived-key>` so real provider credentials never enter the
project environment.

## Local CLI providers

Local providers depend on tools already installed and authenticated on your
machine. If a provider cannot be detected, confirm the binary is available on
your PATH and works from a terminal before opening a support issue.

## Remote API providers

The Add provider form is intentionally compact:

- **Local CLI**: Claude, Codex, or Gemini installed and authenticated on the
  same machine.
- **Remote**: a dropdown of built-in presets.
- **Custom**: a manually entered provider id, display label, compatible base
  URL, and model list.

Manifold includes 27 quick-add presets across hosted APIs and local-server
runtimes. Hosted presets include OpenAI, Anthropic, Gemini API,
DeepSeek, GLM, Mistral, Groq, xAI, OpenRouter, Together, Moonshot/Kimi, Qwen,
Perplexity, Fireworks, Cerebras, Cohere, NVIDIA NIM, SambaNova, MiniMax, Doubao,
ERNIE, Hunyuan, StepFun, and SiliconFlow.

Ollama, LM Studio, and vLLM are local-server presets. They point to localhost
OpenAI-compatible URLs and can be added without an API key when the local server
itself is running without auth. If the local server requires a key, enter it and
Manifold will send it as bearer auth.

Free includes 1 remote or local-server provider. Pro supports up to 10 remote or
local-server providers. Local CLI providers do not count against that remote
provider limit.

## Routes and aliases

Routes create stable model names for clients. Use them when you want to switch a
client from one backend to another without editing the client configuration.
Weighted routing, fallback, and model aliases are Pro capabilities.

## Local Session Keys

Local Session Keys are generated by Manifold for local clients such as Claude
Code, test runners, or project scripts. They authenticate only to the Manifold
localhost gateway. They do not reveal, replace, sell, lease, or broker provider
API keys. Revoke them when a project ends or when a key may have entered logs.

The current generator asks for a label and TTL. Project policies, allow-lists,
usage attribution by project, and bulk revoke are Pro-oriented policy work and
should not be assumed present unless the app UI exposes them.

## Language

Manifold supports English and Simplified Chinese. It can follow the operating
system locale or use a manual override in Settings.
