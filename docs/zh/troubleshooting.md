# 故障排查

## 网关与认证

确认应用正在运行，端口没有被其他程序占用。默认地址为
`http://127.0.0.1:17680/v1`。健康检查、模型列表和推理请求均需要通过 Bearer
或 x-api-key 提供主密钥或有效会话密钥，仅 `/llm.txt` 和 `/llms.txt` 公开。
会话密钥失败时，请检查过期、撤销及 route/provider 限制。Free 最多支持 3 个
有效会话密钥。

## 供应商不可用

HTTP API 请检查地址、密钥和支持的请求格式。浏览器授权账户请检查订阅状态，
授权过期时在供应商页重新连接。授权在浏览器中完成，由 Manifold 自己保存并
刷新 OAuth 令牌。

使用 Ollama、LM Studio 或 vLLM 时，先启动本地服务器并确认 HTTP 地址可达。
只有服务器允许免认证访问时，才可以不填密钥。

## 模型缺失或达到限额

修正 HTTP 地址或密钥后点击 **Refresh models**。远程目录也会在启动后及每 12 小时
刷新；失败时保留已有模型。Free 最多 3 个 HTTP 供应商，Pro 最多 10 个，
浏览器 OAuth 账户不占此限额。

## Routes 与流式请求

确认客户端使用路由名，目标已启用且支持当前协议。Free 包含 1 条路由；
Chat/Messages 可重试失败后切换其他供应商需要 Pro。流式输出开始后不能更换
供应商。上游错误可能直接透传，请根据状态与错误信息检查密钥、限流或模型名称。

## 配对与透传

Pro 的“配对本地工具”代码约 60 秒有效，过期后重新开启配对。
生成密钥需要主密钥或有效配对码。Free 在额度内支持基本密钥生成。

native passthrough 仅支持 GET/POST，拒绝重定向，路径必须保留在配置的上游
origin 内。限制路由范围的会话密钥不能通过透传绕过 Routes。
诊断仅读取应用与网关日志。

## 下载与支持

公开下载地址：https://github.com/lingphi-ai/manifold-support/releases/latest

源码标签更新后，release-sync 发布流程可能尚未完成。反馈时提供版本、平台、
渠道、路径、状态码和脱敏错误，不要提供凭证、令牌或私有提示词。
