# 核心概念

## 网关与供应商

网关默认监听 `127.0.0.1:17680`，仅提供本机环回访问。
供应商是一个 HTTP 后端：托管 API、本地模型服务器或浏览器授权的订阅账户。
远程 API 使用配置好的 OpenAI / Anthropic 兼容地址，OAuth 账户使用订阅后端
与 Manifold 自己保存的令牌。启用或停用供应商会即时生效。

Ollama、LM Studio、vLLM 使用本地 HTTP 地址；上游认证可选。
托管 API 地址需要通过安全 HTTPS 校验。

## 模型目录与 ID

远程目录在添加供应商、点击 Refresh models、启动后以及每 12 小时刷新。
刷新失败时保留已有模型。订阅账户使用维护的模型目录，并按账户信息选择可用模型。

- `provider/model` 强制使用指定供应商，只按第一个斜杠切分。
- 普通模型名按优先级选择兼容的供应商。
- 配置好的 Routes 名称选择 weighted 或 failover 目标。
- Pro 模型别名可以改写客户端模型名。

## 路由与工具调用

路由将固定模型名映射到 provider/model 目标。
`weighted` 按相对权重选择，`failover` 保持目标顺序。
Free 包含 1 条路由；Pro 提供不限数量的路由，以及 Chat/Messages 可重试失败后
的跨供应商回退。流式输出开始后不能更换供应商。

网关将工具调用回传给客户端。内置对话通过同一个网关发送请求；选择工作区后，
两种版本都可使用受限的读取工具。Pro 增加写入和编辑工具，默认要求用户批准。

## 本地会话密钥

`mf_session_` 开头的密钥仅用于认证到 Manifold。应用保存哈希，新密钥只显示
一次，并支持过期和撤销。Free 包含 3 个有效密钥；Pro 提供不限数量的密钥、
项目与 route/provider 策略、审计记录，以及需要手动开启的“配对本地工具”。

## 用量与安全

用量只来自 Manifold 网关记录的请求，包括输入、输出、缓存创建、缓存读取 token
和模型费用估算。Free 保留 7 天，Pro 支持 30 天。诊断仅读取应用和网关日志。

仅 `/llm.txt` 与 `/llms.txt` 公开，健康检查和模型列表需要主密钥或有效会话密钥。
API 密钥与 OAuth 令牌通过操作系统支持的 safeStorage 加密；加密不可用时
拒绝写入，不退回明文。OAuth 记录使用独立本地文件。上游凭证不会返回给客户端。

各分发渠道均使用 HTTP 供应商与浏览器授权账户，区别在于打包和购买流程。
