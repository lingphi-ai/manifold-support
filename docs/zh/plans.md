# 版本与计划

Manifold 提供 Free 和 Pro 两个版本。本地 CLI 服务商在两个版本中都可用，因为
可靠的本地网关是产品的核心价值。

## Free

Free 适合个人本地工作流和首次配置。

- 不限数量的本地 CLI 服务商。
- 1 个远程服务商。
- 兼容 OpenAI 和 Anthropic 的本地网关。
- 7 天用量窗口。
- 只绑定 `127.0.0.1` 的本地网关。

## Pro

Pro 价格为 **$2/year**，适合依赖多个服务商和稳定路由的用户。

- 最多 10 个远程服务商。
- 带加权目标的 Routes。
- 兼容服务商之间的 fallback。
- 模型别名。
- 完整用量历史。
- 通过 GitHub Issues 获得优先支持。

订阅将连接到 Manifold 许可证，并随公开桌面版下载一起启用。价格和限制属于
产品文档；如果应用行为与这里不同，请提交 issue，并附上版本号和简短复现步骤。

## 如何选择

如果你主要使用本机已经登录的 CLI，并且只需要一个远程 API 作为补充，Free
通常足够。如果你需要把不同客户端稳定地指向同一组模型名，或需要在服务商失败
时自动切换到另一个兼容服务商，Pro 会更合适。

计划限制只影响 Manifold 自身的管理能力，不改变上游服务商的收费方式。远程
API 费用仍由对应服务商收取；本地 CLI 是否按 token 计费，也取决于该 CLI 的
账号和订阅规则。
