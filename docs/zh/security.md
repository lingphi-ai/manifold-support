# 安全

Manifold 是本地 HTTP 访问层，不是 token 市场。Manifold 不销售、租借或中转
第三方模型 token。上游账户权限、服务条款和模型费用仍由用户与供应商管理。

## 本地边界与 HTTP 请求

网关只绑定 `127.0.0.1`。仅 `/llm.txt` 和 `/llms.txt` 公开。
健康检查、模型列表和推理请求需要主网关密钥或有效本地会话密钥。
主密钥由 `ldd_` 加上 16 个随机字节的十六进制表示组成。
托管 HTTPS 地址会接受安全校验，本地服务器可按支持的地址配置可选认证。
原生透传仅允许 GET/POST，拒绝重定向，路径不能越过配置的供应商 origin。

设置窗口使用带 nonce 的 Content-Security-Policy、上下文隔离和 preload 桥接。
模型请求使用 HTTP 后端。诊断仅读取应用与网关日志，不导入外部凭证或用量存储。
日志会隐藏敏感凭证以及请求、响应载荷中的敏感字段。

## 凭证存储

配置与密钥文件使用受限本地权限。API 密钥与浏览器 OAuth 令牌使用同一个凭证
编解码器，通过 Electron 异步 safeStorage 和操作系统钥匙串加密；OAuth 记录
保存于独立文件。加密不可用或失败时拒绝写入凭证，不退回明文。访问与刷新令牌
不会通过 renderer 桥接或设置快照暴露。

## 本地会话密钥

`mf_session_` 开头的令牌仅认证到 Manifold。新密钥只显示一次，存储 SHA-256
哈希，使用时进行时间安全比较，并支持过期和撤销。Free 包含 3 个有效密钥；
Pro 支持不限数量、项目策略、允许的 route 名称、供应商范围、审计和工具配对。
“配对本地工具”需要手动开启，约 60 秒后过期。

会话密钥本身不能生成另一把密钥；生成操作需要主密钥或有效配对码。
这些令牌是网关凭证，不是供应商 API 密钥、模型额度，也不能绕过上游账单。

## 工作区与反馈

选择工作区后，内置对话可运行受限读取工具；Pro 增加写入与编辑，默认要求批准。
文件访问会校验工作区范围及符号链接。提交问题前请隐藏上游密钥、网关与会话
密钥、OAuth 令牌、许可证、私有提示词和原始响应。
